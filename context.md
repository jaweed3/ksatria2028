## Core Narrative

KSATRIA 2028 bukan sekadar acara peringatan. Ini adalah **gerakan moral kebangsaan** pemuda Indonesia menyambut satu abad Sumpah Pemuda. Di tengah polarisasi politik, disinformasi digital, dan dinamika menjelang Pemilu 2029, KSATRIA 2028 hadir sebagai **"Penyeimbang Moral Nasional"** — ruang persatuan, dialog, dan konsolidasi yang inklusif, netral, dan konstruktif.

**Konsep Besar:** *"Simulasi Masa Depan Indonesia"* — menghadirkan miniatur keberagaman Indonesia (38 provinsi, berbagai komunitas, organisasi, agama, adat) dalam satu forum nasional untuk bersama merumuskan arah Indonesia Emas 2045.

## Brand Voice & Tone

- **Bahasa:** Bahasa Indonesia yang formal, bertenaga, kebangsaan — bukan bahasa startup
- **Nada:** Heroik, inklusif, historis, forward-looking
- **Hindari:** Bahasa Inggris berlebihan, tone casual Gen-Z, corporate buzzwords
- **Gunakan:** Kata-kata seperti "bangsa", "pemuda", "persatuan", "kebangsaan", "generasi", "masa depan", "arah Indonesia"

---

## Technical Constraints

- **Format:** Single HTML file (self-contained, zero external dependencies kecuali Google Fonts CDN)
- **Framework:** Vanilla HTML + CSS + JS (NO React, NO Vue, NO build tools)
- **Fonts:** Load dari Google Fonts (CDN)
- **Images:** Gunakan placeholder / CSS-generated visuals atau SVG — jangan external image URLs yang bisa break
- **Icons:** Inline SVG atau unicode characters
- **Responsive:** Mobile-first, breakpoint di 768px dan 1200px
- **Performance:** Minimal JS, animasi berbasis CSS sebisa mungkin
- **Deployment:** Vercel static deploy — output harus `index.html` siap pakai
- **No frameworks:** Tidak boleh ada npm, webpack, vite, atau build step
- **Sections Navigation:** Sticky navbar dengan anchor links ke setiap section
- **Accessibility:** Semantic HTML, proper heading hierarchy, sufficient color contrast

## Do's and Don'ts for Agent

**DO:**
- Buat setiap section dengan konten nyata dari proposal (bukan placeholder lorem ipsum)
- Gunakan semua nama, tanggal, fakta dari proposal ini
- Buat countdown timer yang fungsional ke 28 Oktober 2028
- Implementasi smooth scroll dan sticky nav
- Buat animasi entrance untuk setiap section
- Gunakan motif visual yang identik dengan kebangsaan Indonesia (batik-inspired, garuda, merah-putih-emas)

**DON'T:**
- Jangan gunakan lorem ipsum
- Jangan buat placeholder "Coming Soon" untuk konten yang sudah ada di proposal
- Jangan gunakan color scheme purple/blue gradient yang generik
- Jangan buat layout yang terlihat seperti template startup SaaS
- Jangan import external JS libraries yang bisa fail (no jQuery, no Bootstrap CDN yang tidak reliable)
- Jangan buat file terpisah — semua harus dalam 1 `index.html`
